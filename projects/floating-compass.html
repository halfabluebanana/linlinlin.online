floating compass

A real-time location sharing tool that reorients presence — not to north, but to each other. Create a room, share the key, and see where the people you care about are in the world. Each user's compass points toward the others, layered over a live map of their location.

Stack: WebSocket · Socket.io · Node.js · OpenStreetMap · Web Geolocation API

Role: designer + maker · physical computing · spatial design
