UNICEF Global Child Hazard Dashboard

Every district-level case study in a tool built for policymakers was silently drawing the wrong map — the boundary cache held no district rows at all, so each one fell back to its province or country outline without erroring.

The dashboard lets policymakers and UNICEF country offices see how many children sit inside a given climate hazard zone, by overlaying hazard layers on population rasters within an administrative boundary. The answer it gives is only as good as the boundary it computes over, which is where the problem was.

The second administrative level — districts — was missing from the boundary cache entirely. The district selector returned nothing, code lookups failed, and every district-scoped case study quietly fell back to drawing its parent province or country. Nothing threw an error. A user reading a district case study saw a map, and the map was of the wrong area. The upstream boundary API had been retired and was answering 410, but the public blob exports still served all three levels, so I rebuilt the cache from those: 289 country boundaries, 3,578 provinces, and districts from zero to 41,092, covering all 289 countries, with nothing from the old cache lost.

Worth separating two things that looked like one bug. The exposure figures at country and province level were never wrong. Exposure sums the population raster directly over whichever boundary is selected, so the coarser levels come from pixels rather than from aggregating districts upward. The missing level was a gap in coverage, not in accuracy — and saying that precisely mattered, because the alternative reading would have put every number the tool had ever produced in doubt.

I also finished the case-study schema migration: 638 records validating against the new version. Eight of them were hand-authored and could not go through the main migration path, which reads every field from an upstream API keyed on a slug those records do not have — so they needed a separate migration rather than a manual edit, on the principle that a hand-fixed record is a record nobody can re-run. Restoring districts then resolved 24 more location names that had previously had nothing to match against.

Stack: Python · Flask · SQLite · GeoJSON · population raster analysis · GDAL
